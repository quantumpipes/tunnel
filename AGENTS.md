# AGENTS.md: tunnel

Encrypted remote access for on-premises AI. Bash + Makefile toolkit that automates WireGuard VPN setup, peer management, and service exposure over post-quantum TLS. Apache 2.0.

## Stack

- Bash 4.0+ with `set -euo pipefail`, Makefile orchestration.
- WireGuard (outer layer): Curve25519 key exchange, ChaCha20-Poly1305, BLAKE2s.
- Caddy (inner layer): Go 1.24+ for post-quantum TLS (X25519MLKEM768 hybrid), AES-256-GCM, Ed25519 internal CA.
- Required tools: `jq`, `wg`, `wg-quick`, `openssl`, `qrencode`, `doctl` (DigitalOcean helper; `curl` fallback).
- Optional: `qp-capsule` (pip) for Capsule-sealed audit entries.
- Tests: bats-core (370+ tests: unit, integration, smoke).

## Commands

```bash
# Direct scripts
./tunnel-setup-relay.sh [--provider=ssh|local|digitalocean] [--host=IP]
./tunnel-join.sh <endpoint> <relay-public-key>
./tunnel-add-peer.sh <name>
./tunnel-remove-peer.sh <name>
./tunnel-status.sh
./tunnel-rotate-keys.sh [CONFIRM=1]
./tunnel-open.sh --name <service> --to <host:port> [--port <N>]
./tunnel-close.sh --name <service>
./tunnel-list.sh

# Makefile (20+ targets)
make tunnel-setup-local | tunnel-setup-ssh | tunnel-setup-do
make tunnel-add-peer | tunnel-status | tunnel-rotate-keys | tunnel-open | tunnel-close | tunnel-list
make test | test-unit | test-integration | test-smoke
```

## Style

- **No em dashes** in code, commits, or docs. Use commas, periods, colons, parentheses.
- `set -euo pipefail` at the top of every script.
- Every function-local variable declared with `local`.
- Quote all expansions: `"$var"`, not `$var`.
- **Never** `eval`. **Never** `shell=True` in any pipeline.
- Validate inputs with explicit regex: `^[a-zA-Z0-9_-]+$` for names.
- File permissions: `600` for keys, `700` for key directories. These are non-negotiable.
- shellcheck-clean. Tests in AAA (Arrange / Act / Assert) pattern.

Canonical usage:
```bash
./tunnel-add-peer.sh alice
# generates Ed25519 keypair + preshared key, assigns 10.8.0.x,
# writes WireGuard client config, emits QR code, appends audit entry
```

## Git workflow

- Conventional commits with scope: `feat(open): ...`, `fix(registry): ...`, `docs(crypto-notice): ...`.
- **Never** include `Co-Authored-By`, `Generated by`, or any AI attribution.
- Single-change PRs. Tests for every new function. Run `make test` before pushing.
- Update `README.md` and `CRYPTO-NOTICE.md` together when cryptographic behavior changes.

## Boundaries

**Always:**
- Keep file permissions strict: `600` on keys, `700` on key directories.
- Preserve the audit-log format. Golden conformance vectors must keep passing.
- Honor the two-layer crypto model: WireGuard outer, PQ TLS inner.

**Ask first:**
- Adding a required system dependency beyond the listed tools.
- Changing the WireGuard address range or routing defaults.
- Widening the public CLI surface (new `tunnel-*.sh` scripts).

**Never:**
- Use `eval` or unquoted expansions.
- Skip input validation on peer names, service names, or hostnames.
- Delete archived configs (revocation is immediate, archival is permanent for audit).
- Require a cloud control plane. Air-gap compatibility is product scope.
- Introduce deprecated crypto. Allowlist: X25519 (Curve25519), ChaCha20-Poly1305, BLAKE2s, X25519MLKEM768, AES-256-GCM, Ed25519, SHA3-256. Forbidden: MD5, SHA1, RSA, ECDSA-P256, 3DES, RC4.
